# Kortkommandon

## Provlyssning {#provlyssning}

Gäller under **▶ Playtest** i admin och i lyssnarappens simulering på datorn.

| Tangent | Gör |
|---|---|
| [[W]] eller [[↑]] | Gå framåt |
| [[S]] eller [[↓]] | Gå bakåt |
| [[←]] [[→]] eller [[Q]] [[E]] | Vrid dig |
| [[A]] [[D]] | Kliv åt sidan |
| Håll [[Shift]] | Skynda på |

Tangenterna fungerar inte medan du skriver i ett textfält.

## Kartan {#kartan}

| Gör så här | Händer |
|---|---|
| Dubbelklick medan du ritar | Avslutar stigen, zonen eller rutten |
| Dubbelklick annars | Zoomar in |
| Scrollhjul | Zoomar |
| [[Enter]] i **Go to place…** | Söker efter platsen |

## Textfält {#text}

| Var | Tangent | Gör |
|---|---|---|
| **New course** → **Name** | [[Enter]] | Skapar rundan |
| AI-assistentens skrivruta | [[Enter]] | Skickar |
| AI-assistentens skrivruta | [[Shift]] + [[Enter]] | Ny rad |
| Namnet på ett ljudkort | [[Enter]] | Sparar namnet |
| Namnet på ett ljudkort | [[Shift]] + [[Enter]] | Ny rad |
| Sökrutan i hjälpen | [[Esc]] | Tömmer sökningen |
