# Ordlista

| Ord | Betyder |
|---|---|
| **Admin** | Det här verktyget, där rundor byggs. |
| **Lyssnarappen** | Webbsidan besökaren öppnar på mobilen för att gå rundan. |
| **Runda** (*course*, *walk*) | En ljudvandring: punkter, zoner, rutt och texter. |
| **Punkt** (*point*) | Ett ljud på kartan. Finns i fem [typer](#help/punkttyper). |
| **Static** | Punkt som står still. |
| **Circling** | Punkt som cirklar runt en mittpunkt. |
| **Path** | Punkt som vandrar längs en stig. |
| **Follow** | Punkt som följer efter besökaren när den kommit nära. |
| **Triggered** | Stig som sätter i gång när besökaren kommer nära. |
| **Hörbar radie** (*audible radius*) | Hur långt bort en punkt hörs. |
| **Triggerradie** (*trigger radius*) | Hur nära besökaren måste komma för att något ska starta. |
| **Stig** (*path*) | Linjen ett rörligt ljud följer. |
| **Hörn** (*vertex*, *corner*) | En brytpunkt i en stig, en zon eller rutten. |
| **Stopp** (*stop*) | Ett hörn där en stig pausar och spelar en berättelse. |
| **Paus** (*dwell*) | Hur länge en stig stannar vid ett stopp. |
| **Färdljud** (*travelling audio*) | Ljudet en stig spelar medan den rör sig. |
| **Guide** | En återanvändbar berättarfigur med persona, röst och vilo-ljud. |
| **Persona** | Beskrivningen av en guides personlighet och sätt att prata. |
| **Vilo-ljud** (*idle sound*) | Ljudet en guide gör mellan stoppen. |
| **Koppel** (*leash*) | Avståndet där en väntande stig stannar och väntar på besökaren. |
| **Kunskapsbank**, **fakta** (*facts*) | Texten en berättelse skrivs utifrån. |
| **Manus** (*narration*) | Det som faktiskt sägs i ett klipp. |
| **Inläsning** (*render*) | När en text görs om till tal. |
| **Ljudtagg** | En instruktion till rösten inom hakparentes, t.ex. `[whispers]`. |
| **Språkversion** (*narration language*) | En inspelning på ett annat språk, vald efter telefonens språk. |
| **Flagga** (*flag*) | Ett ord som sätts när en punkt hörts och kan låsa upp andra punkter. |
| **Exklusiv grupp** (*exclusive group*, *crossroads*) | Punkter där besökaren bara kan välja en; de andra låses. |
| **Nästa ljud** (*next sound*) | Punkten besökaren leds vidare till efter en annan. |
| **Dold** (*hidden*) | En punkt som hörs men inte syns. |
| **Riktad** (*directional*) | En punkt som bara hörs inom en kil. |
| **Akustisk zon** (*zone*) | Ett område med egen klang och bakgrundsloop. |
| **Klang**, **efterklang** (*reverb*) | Hur rummet låter: utomhus, rum, sal, katedral, tunnel. |
| **Bakgrundsloop** (*ambience*, *background loop*) | Ljudet som spelas hela tiden i en zon. |
| **Planerad rutt** (*route*) | Vägen besökaren är tänkt att gå. |
| **Individuell tid** | Varje besökare har sin egen klocka för rörliga ljud. |
| **Gemensam tid** (*global*) | Alla besökare hör ett rörligt ljud på samma plats samtidigt. |
| **Utkast** | Det du ser i admin. Besökarna hör det först när du publicerar. |
| **Publicera** | Skicka ut den aktuella versionen till besökarna. |
| **Flight check** | Kontrollen som letar fel innan publicering. |
| **Kort adress** (*short address*, *slug*) | Sista delen av rundans länk. |
| **Provlyssning** (*playtest*) | Att gå rundan vid datorn med en virtuell lyssnare. |
| **Simulering** | Lyssnarappen på datorn, med `?sim=1` eller **Try it on this screen**. |
| **Eyes-up** | Läge där besökaren navigerar efter ett ekolodspip i stället för skärmen. |
| **Scouting** | Att samla platser i fält med mobilen (`/?scout`). |
| **Set** | En samling scoutade platser. |
| **Discover** | Verktyget som hittar sevärdheter i OpenStreetMap. |
| **Ljudbiblioteket** | Alla uppladdade och genererade klipp, under fliken **Sounds**. |
| **Krediter** (*credits*) | Det som dras hos ElevenLabs eller OpenRouter när du genererar något. |
